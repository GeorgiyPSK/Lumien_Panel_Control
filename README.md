# Lumien Control — HTTP-мост для панелей Lumien

Простой HTTP-сервер для управления панелями **Lumien Standard G2** по TCP (команды из документации производителя).
Поднимает локальный REST-подобный API и веб-страницу с кнопками — можно управлять панелями из браузера, `curl`, Home Assistant, скриптов и т.п.

---

## Возможности

-  Управление **двумя панелями** одновременно или по отдельности
-  HTTP-API с JSON-ответами (удобно для автоматизации)
-  Встроенная веб-страница с кнопками «Включить / Выключить / Состояние»
-  Прямая отправка TCP-команд по протоколу Lumien (порт `4664`)
-  Подробное логирование в консоль (отправка/ответ/ошибки)
-  **Ноль внешних зависимостей** — только стандартная библиотека Python 3.7+

##  Быстрый старт

```bash
python3 lumWeb.py
После запуска откройте в браузере:


http://localhost:9999
Появится страница с кнопками для каждой панели и общими действиями.

Настройка
Все настройки — в начале файла lumWeb.py, в блоке # --- НАСТРОЙКИ ---.
Перед запуском обязательно замените IP-адреса на реальные адреса ваших панелей.


# --- НАСТРОЙКИ ---
PANELS = {
    "panel1": {"ip": "0.0.0.0", "port": 4664, "name": "Панель 1 (0.0.0.0)"},
    "panel2": {"ip": "0.0.0.0", "port": 4664, "name": "Панель 2 (0.0.0.0)"},
}
HTTP_PORT = 9999             # Порт HTTP-сервера
TIMEOUT   = 3                # Таймаут ожидания ответа (сек)
# --- КОНЕЦ НАСТРОЕК ---
Параметр	Описание
ip	IP-адрес панели в локальной сети
port	TCP-порт панели (по умолчанию 4664)
name	Отображаемое имя (видно в JSON-ответах и на странице)
HTTP_PORT	Порт, на котором поднимается HTTP-сервер
TIMEOUT	Таймаут ожидания ответа от панели, сек
Также обновите подписи на веб-странице
В методе _help_page() замените ---ip--- на реальные адреса, чтобы страница выглядела аккуратно:

html
<div class="card">
  <h2>Панель 1 (---ip---)</h2>
  <button onclick="call('/panel1/on')">Включить</button>
  <button class="red" onclick="call('/panel1/off')">Выключить</button>
  <button onclick="call('/panel1/status')">Состояние</button>
</div>

<div class="card">
  <h2>Панель 2 (---ip---)</h2>
  <button onclick="call('/panel2/on')">Включить</button>
  <button class="red" onclick="call('/panel2/off')">Выключить</button>
  <button onclick="call('/panel2/status')">Состояние</button>
</div>
HTTP-эндпоинты
Метод	Путь	Действие
GET	/ или /help	Веб-страница с кнопками
GET	/on	Включить обе панели
GET	/off	Выключить обе панели
GET	/status	Запросить состояние обеих панелей
GET	/panel1/on	Включить панель 1
GET	/panel1/off	Выключить панель 1
GET	/panel1/status	Состояние панели 1
GET	/panel2/on	Включить панель 2
GET	/panel2/off	Выключить панель 2
GET	/panel2/status	Состояние панели 2
Также поддерживаются алиасы:
screen_on / display_on, screen_off / display_off, state / screen_status.

Примеры запросов
Включить обе панели:

bash
curl http://localhost:9999/on
Выключить только панель 2:

bash
curl http://localhost:9999/panel2/off
Получить состояние панели 1:

bash
curl http://localhost:9999/panel1/status
Пример JSON-ответа на /status:

json
{
  "action": "screen_status",
  "target": "all",
  "results": {
    "panel1": {
      "name": "Панель 1 (192.168.0.56)",
      "ip": "192.168.0.56",
      "status": "success",
      "screen": "on",
      "raw_response": "3A 30 31 72 45 30 30 31 0D",
      "error": null
    },
    "panel2": {
      "name": "Панель 2 (192.168.0.62)",
      "ip": "192.168.0.62",
      "status": "success",
      "screen": "off",
      "raw_response": "3A 30 31 72 45 30 30 30 0D",
      "error": null
    }
  }
}
Поле screen может принимать значения: "on", "off", "unknown (...)" или null.

Используемые TCP-команды
Согласно документации Lumien Standard G2:

Команда	Hex	Назначение
Экран OFF	3A 30 31 53 45 30 30 30 0D	Выключить экран
Экран ON	3A 30 31 53 45 30 30 31 0D	Включить экран
Запрос состояния	3A 30 31 47 45 30 30 30 0D	Получить статус экрана
Ответ на запрос состояния содержит 000 (OFF) или 001 (ON) — сервер автоматически парсит его в человекочитаемое значение.

Как это работает
HTTP-запрос приходит на http://<host>:9999/<action>.

Сервер открывает TCP-соединение с панелью по её IP и порту 4664.

Отправляет соответствующую бинарную команду.

Ждёт ответ (до TIMEOUT секунд) и, если нужно, парсит статус.

Возвращает JSON-структуру с результатом по каждой панели.

Требования
Python 3.7+

Внешних зависимостей нет — только стандартная библиотека (socket, logging, json, http.server)

Сетевая доступность панелей по TCP-порту 4664

Диагностика
Ошибка отправки: ...	Верный ли IP панели? Пингуется ли она?
Таймаут ожидания ответа	Панель не отвечает — проверьте порт 4664 и firewall
screen: "unknown (...)"	Панель вернула нестандартный ответ — смотрите поле raw_response
Страница не открывается	Порт 9999 занят или заблокирован; измените HTTP_PORT
Все действия логируются в консоль в формате:


2025-01-01 12:00:00 - INFO - [192.168.0.56] Отправлено (TCP): 3A 30 31 53 45 30 30 31 0D
2025-01-01 12:00:00 - INFO - [192.168.0.56] Ответ: 3A 30 31 72 45 30 30 31 0D
